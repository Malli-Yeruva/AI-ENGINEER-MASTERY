# AI Engineer Roadmap

This repository is a personal learning workspace for becoming an AI/ML engineer with strong software engineering fundamentals.

## Structure

- `00_Master_Plan/` — learning constitution, roadmap, progress, and study resources
- `01_Python/` — Python fundamentals, notes, exercises, assignments, and mini projects
- `02_DSA/` — data structures and algorithms practice
- `03_Machine_Learning/` — ML concepts and experiments
- `04_Deep_Learning/` — neural networks and deep learning study notes
- `05_Computer_Vision/` — vision models and image processing projects
- `06_MLOps_Deployment/` — deployment, Docker, FastAPI, and MLOps
- `07_System_Design/` — system design notes and interview prep
- `08_Projects/` — portfolio-style projects and build work
- `Assets/` — diagrams, images, and supporting files

## How to use this repo

1. Start with the constitution in `00_Master_Plan/AI_Engineer_Learning_Constitution.md`.
2. Follow the roadmap in `00_Master_Plan/Roadmap.md`.
3. Update progress after each study session.
4. Keep notes, exercises, and interview questions inside the relevant topic folder.
