# Common Mistakes Log

## Python
- Confusing `==` with `is`
- Using mutable default arguments carelessly
- Forgetting that assignment creates references
- Ignoring scope and LEGB rules
- Not dry-running algorithms before coding

## Problem Solving
- Jumping into code without understanding the problem
- Skipping edge cases
- Forgetting to analyze time and space complexity

## Interviews
- Giving memorized answers without explaining reasoning
- Not connecting concepts to real-world use cases
