# Roadmap

## 90-Day Learning Roadmap

### Phase 1 — Python Foundations
- Python basics and core syntax
- Functions, scope, closures, decorators
- `*args`, `**kwargs`, type hints, OOP
- Small exercises and interview questions

### Phase 2 — DSA and Problem Solving
- Arrays, strings, linked lists, stacks, queues
- Trees, heaps, graphs, hash maps
- LeetCode-style practice and dry run sessions

### Phase 3 — Machine Learning
- Supervised learning basics
- Evaluation metrics and data preprocessing
- Regression, classification, clustering

### Phase 4 — Deep Learning
- Neural networks
- PyTorch/TensorFlow basics
- CNNs and fundamentals of deep learning

### Phase 5 — Computer Vision
- Image processing fundamentals
- CNNs for vision tasks
- OpenCV and project work

### Phase 6 — Deployment and MLOps
- FastAPI, Docker, REST APIs
- Model packaging and deployment
- Cloud basics and production workflows

### Phase 7 — System Design and Interviews
- System design fundamentals
- Resume and interview preparation
- Projects and mock interviews
